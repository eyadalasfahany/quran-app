# Notice for the book and chapter titles (ADR 0076)

The book titles and chapter titles in this folder come from the OpenITI project (release 2023.1.8), licensed under CC BY-NC-SA 4.0. Some hadith texts also come from OpenITI. Changes were made: formatting markers were removed, and the titles were mapped to the hadith numbering of fawazahmed0/hadith-api. The ShareAlike term applies to this data.
