# Tanzil Quran text

Verbatim copies of the Tanzil Project's Quran text and chapter metadata. This is the only Quran text bundled in the app.

## Source

- Text: Tanzil Quran Text (Uthmani, Version 1.1)
- Text: Tanzil Quran Text (Simple, Version 1.1), the Imla'i spelling
- Metadata: Quran metadata 1.0
- Project: Tanzil Project — tanzil.net
- Licence: Creative Commons Attribution 3.0 (CC BY 3.0)
- Licence page: https://tanzil.net/docs/text_license
- Date recorded: 2026-10-27

The files in this directory were pinned on that date. Their bytes are the downloaded files; nothing in them was edited, reformatted, or re-encoded.
